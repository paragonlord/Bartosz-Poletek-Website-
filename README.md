# Bartosz Poletek — Website

Plain HTML/CSS, hosted on GitHub Pages at bartoszpoletek.com.

- **Add a project:** copy the `<article class="project">` block in `index.html`, put the image in `images/`, and replace `<div class="thumb">Coming soon</div>` with `<div class="thumb"><img src="images/your-file.jpg" alt="..."></div>`.
- **Dutch and Polish versions:** `nl/index.html` and `pl/index.html` are translated copies of the page. When you change text or add a project, update all three files.
- **Contact details:** edit the `#contact` footer (the giant email is in there too) in `index.html`.
- **Colors & fonts:** change the variables at the top of `style.css` (Cormorant Garamond for text, Herr Von Muellerhoff for the name, self-hosted in `fonts/`).
