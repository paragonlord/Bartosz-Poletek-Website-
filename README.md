# Bartosz Poletek — Website

Plain HTML/CSS, hosted on GitHub Pages at bartoszpoletek.com.

- **Add a project:** copy an `<article class="card">` block in `index.html`, put the image in `images/`, and replace `<div class="thumb">Project image</div>` with `<div class="thumb"><img src="images/your-file.jpg" alt="..."></div>`.
- **Contact details:** edit the `#contact` section in `index.html`.
- **Colors & fonts:** change the variables at the top of `style.css` (fonts are Playfair Display + Karla from Google Fonts).
